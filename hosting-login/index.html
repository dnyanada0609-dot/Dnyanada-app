शिक्षक खाते व्यवस्थापन

फक्त अधिकृत Admin ला वाचन आणि बदल करण्याची परवानगी. खाते सक्रिय करणे म्हणजे पैसे मिळाल्याची पडताळणी नव्हे. नाव व मोबाईल बदलल्याने Firebase Authentication लॉगिन आयडी बदलत नाही.

वार्षिक सदस्यत्व शुल्क

नवीन सदस्यत्वासाठी शुल्क. आधीच्या सदस्यत्वांची रक्कम बदलणार नाही.

नवीन शिक्षक नोंदणी

प्रथम Firebase Authentication → Users मध्ये शिक्षकाचे Email/Password खाते तयार करा. त्या खात्याचा UID येथे भरा. पासवर्ड या पॅनेलमध्ये टाकू नका.

सुरक्षिततेसाठी नवीन शिक्षक खाते सुरुवातीला निष्क्रिय राहील. सदस्यत्व व पेमेंट पडताळल्यानंतरच सक्रिय करा.

शिक्षक शोधा

यादी पानानुसार दाखवली जाते; शोध सध्याच्या पानापुरता आहे.

महत्त्वाचे: ही विद्यमान Admin Panel ची सुधारित आवृत्ती आहे. Authentication खाते तयार करणे/पासवर्ड रीसेट, APK सदस्यत्व अंमलबजावणी आणि सर्व्हरवरील प्रवेश नियंत्रण स्वतंत्रपणे तपासणे आवश्यक आहे. या पॅनेलमधील UID नोंदणी Firebase Authentication खाते तयार करत नाही. शिक्षकांचे पासवर्ड Admin Panel मध्ये साठवू नका. Firebase Security Rules लागू राहतात.
