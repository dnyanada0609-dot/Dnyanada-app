शिक्षक खाते व्यवस्थापन

फक्त अधिकृत Admin ला वाचन आणि बदल करण्याची परवानगी. खाते सक्रिय करणे म्हणजे पैसे मिळाल्याची पडताळणी नव्हे. नाव व मोबाईल बदलल्याने Firebase Authentication लॉगिन आयडी बदलत नाही.

ही स्वतंत्र वेब चाचणी आहे. नवीन Firebase Authentication वापरकर्ता तयार करणे, मोबाईल क्रमांकाने लॉगिन, स्वतंत्र पेमेंट पडताळणी आणि मूळ APK मध्ये प्रवेश देणे अद्याप जोडलेले नाही. Firebase Security Rules कायम लागू राहतात. पासवर्ड येथे कुणालाही पाठवू नका.
